# Contributing

Thank you for helping improve EchoMere.

1. Open an Issue before a large behavioral or architectural change.
2. Create a focused branch and keep unrelated changes separate.
3. Run the backend and frontend checks documented in the README.
4. Do not include credentials, private user data, generated databases, or assets you do not have permission to distribute.
5. Submit a pull request that explains the user impact, security implications, and verification performed.

By contributing, you agree that your contribution is licensed under Apache-2.0.
